During my internship, I actively shared technical insights and architectural case studies with the community. Below is the list of technical blogs I authored and posted on the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community page:

### [Blog 1 - INTEGRATING AMAZON EVENTBRIDGE INTO YOUR SERVERLESS APPLICATIONS](3.1-Blog1/)

This blog explores how to connect serverless services with an event-driven architecture — AWS Lambda producers publish events, Amazon EventBridge rules route them to consumers, and everything is deployed declaratively with AWS SAM.

### [Blog 2 - BUILDING, DEPLOYING, AND OPERATING CONTAINERIZED APPLICATIONS WITH AWS FARGATE](3.2-Blog2/)

This blog presents an end-to-end CI/CD workflow for containers: Amazon ECS with the AWS Fargate launch type behind an Application Load Balancer, built and deployed through AWS CodeBuild and AWS CodePipeline.

### [Blog 3 - HOW TO SEND YOUR FIRST EMAIL ON AMAZON SES](3.3-Blog3/)

This blog covers verifying a domain, requesting production access, and sending your first transactional email with Amazon SES through the console and the AWS SDKs.
