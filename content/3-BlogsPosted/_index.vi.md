Trong thời gian thực tập, tôi đã chia sẻ các bài phân tích kỹ thuật và kiến trúc với cộng đồng. Dưới đây là các bài blog tôi đã đăng trên [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj):

### [Blog 1 - TÍCH HỢP AMAZON EVENTBRIDGE VÀO ỨNG DỤNG SERVERLESS](3.1-Blog1/)

Bài viết trình bày cách kết nối các dịch vụ serverless theo kiến trúc event-driven — AWS Lambda producer publish event, Amazon EventBridge routing tới consumer, toàn bộ triển khai khai báo bằng AWS SAM.

### [Blog 2 - XÂY DỰNG, TRIỂN KHAI VÀ VẬN HÀNH ỨNG DỤNG CONTAINER VỚI AWS FARGATE](3.2-Blog2/)

Bài viết giới thiệu quy trình CI/CD trọn vẹn cho container: Amazon ECS với launch type AWS Fargate phía sau Application Load Balancer, build và deploy bằng AWS CodeBuild và AWS CodePipeline.

### [Blog 3 - CÁCH GỬI EMAIL ĐẦU TIÊN VỚI AMAZON SES](3.3-Blog3/)

Bài viết hướng dẫn xác minh domain, xin quyền production và gửi email transactional đầu tiên bằng Amazon SES qua console và AWS SDK.
